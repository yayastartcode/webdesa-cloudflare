# Panduan penggunaan website Desa Lomaer

- [Unduh PDF melalui desalomaer.com — 35 halaman](https://desalomaer.com/api/uploads/0c03e3bb-adf6-4ac3-950c-73a3fa72097b.pdf)
- [Salinan PDF di repository](Panduan-Penggunaan-Website-Desa-Lomaer.pdf)
- [Sumber teks panduan](panduan-penggunaan.md)

Versi 1.0, 7 November 2026. Alamat yang digunakan dalam panduan adalah **https://desalomaer.com**, dengan login admin **https://desalomaer.com/login**.

Panduan mencakup penggunaan website publik, login/keluar, navigasi desktop dan ponsel, upload, seluruh menu dashboard, penerbitan konten, status section, pengaduan, manajemen akun, laporan/cetak, checklist kerja, dan pemecahan masalah. Daftar isi dan tautan pada PDF dapat diklik; setiap bab menjadi satu halaman agar mudah dipelajari dan dicetak.

Seluruh screenshot admin dibuat dari aplikasi yang sama dengan data sintetis pada database dan bucket lokal sementara. Nama, email, nomor, angka, jadwal, gambar, dan tulisan contoh tidak menunjukkan data Production. Tidak ada password, token, informasi akun sebenarnya, atau data pribadi warga dalam panduan.

Pembuatan dokumen ini tidak mengubah website atau data Production. Perubahan aplikasi setelah versi panduan ini dapat memerlukan pembaruan petunjuk dan gambar.
